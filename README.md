# Seabattle

Аркадная игра в стиле советского «Морского боя»: взгляд из перископа, корабли плывут по горизонту, игрок целится и пускает торпеды.

## Движок

**Phaser 3** + Vite (WebGL в браузере).

## Запуск

```bash
npm install
npm run dev
```

Сборка для хостинга:

```bash
npm run build
```

Папка `dist/` — готовый статический сайт.

## Управление

- **Мышь:** води влево/вправо — крутит перископ; ЛКМ — торпеда
- **ПК:** ← → / A D — прицел; пробел — торпеда; **R** — заново
- **Телефон:** кнопки ◀ ▶; **ГИРО** — наклон
- **G** — смена оси гироскопа для теста

## Статус

Phaser 3 прототип: перископ, корабли, торпеды, HUD, гироскоп (опционально).
