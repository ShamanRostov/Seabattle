# Seabattle

Аркадная игра в стиле советского «Морского боя»: взгляд из перископа, корабли плывут по горизонту, игрок целится и пускает торпеды.

## Движок

**Phaser 3** + Vite (WebGL в браузере).

## Запуск

```bash
npm install
npm run dev
```

Сборка для хостинга:

```bash
npm run build
```

Папка `dist/` — готовый статический сайт.

## Управление

- **ПК:** ← → / A D — прицел; пробел / «ПУСК» — торпеда; **R** — заново
- **Телефон:** кнопки ◀ ▶ ПУСК; кнопка **ГИРО** — наклон (на iOS нужен жест/разрешение)
- **G** — переключить ось гироскопа (влево-вправо ↔ вперёд-назад) для теста

## Статус

Phaser 3 прототип: перископ, корабли, торпеды, HUD, гироскоп (опционально).
