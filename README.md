# Seabattle

Аркадная игра в стиле советского «Морского боя»: взгляд из перископа, корабли плывут по горизонту, игрок целится и пускает торпеды.

## Движок

**Phaser 3** + Vite (WebGL в браузере).

## Запуск

```bash
npm install
npm run dev
```

Сборка для хостинга:

```bash
npm run build
```

Папка `dist/` — готовый статический сайт.

## Управление

- **ПК:** ← → или A/D — поворот перископа; пробел / клик по «ПУСК» — торпеда
- **Телефон:** экранные кнопки; гироскоп добавим после тестов наклона

## Статус

Каркас Phaser + простой прототип сцены (перископ, корабли, торпеды).
