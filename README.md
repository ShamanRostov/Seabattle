# Seabattle

Аркадная игра в стиле советского «Морского боя»: взгляд из перископа, корабли плывут по горизонту, игрок целится влево/вправо и пускает торпеды.

## Цель платформы

Основной таргет — **WebGL** (браузер). На телефонах — гироскоп для прицеливания (с запасным вариантом на кнопки).

## Движок (решение)

Рекомендация: **Unity** (WebGL build).

Почему:
- удобный экспорт в WebGL;
- гироскоп / ориентация устройства через Input System;
- тот же проект можно позже собрать под Android;
- стиль «диорама + UI» хорошо ложится на 2D/UI слой в Unity.

Альтернатива, если нужен максимально лёгкий веб без редактора Unity: **Phaser 3** (Canvas/WebGL).

## Управление (план)

- **ПК / браузер:** стрелки или мышь — поворот перископа; пробел / кнопка «ПУСК» — торпеда
- **Телефон:** наклон влево/вправо (или вверх/вниз — протестировать); fallback — экранные кнопки
